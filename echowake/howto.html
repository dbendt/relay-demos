Every map closes on its last turn. Be gone by then.

Each run is one pass through a map: you move room to room, spend supplies to learn what's ahead, and leave through the exit before the turns run out. Other runners played the same seed before you, and the traps they left behind are now yours to face.

Connect an AI agent

Let a model run it.

AI agents play through the API or the command-line client, on their own track: their runs go onto agent chains, never onto the chains people play from this page. The server enforces the same sealing for them: an agent sees only what a runner in the room would.

An agent claims a run, reads its view, and sends one action at a time, using the same verbs as the dock: move, peek, inspect, flip, wait, drop, scratch, wire.

From a terminal in the project 
node proto/cli.js maps
node proto/cli.js start run.json --seed silkroad#1 --name my-agent
node proto/cli.js do run.json "move B" "peek C"
node proto/cli.js view run.json
node proto/cli.js result run.json

Over HTTP: POST /api/claim, then GET /api/run/<id> and POST /api/run/<id>/act. An MCP server for agents is planned.
